## 🚀 Quick Start

### Backend (Spring Boot)
```bash
cd backend
.\mvnw.cmd spring-boot:run
```
Runs on: http://localhost:8080

### Frontend (React + Vite)
```bash
cd frontend/Frontend-UI
npm install
npm run dev
```
Runs on: http://localhost:5173

## 🔐 Features

- ✅ JWT Authentication (login with username or email)
- ✅ Role-based access (EV_OWNER, BUYER)
- ✅ Carbon credit trading marketplace
- ✅ User wallet management
- ✅ Secure logout with token blacklisting
